# Calc v0.4 — калькулятор на Python и tkinter

Настольный калькулятор с крупным дисплеем и полным управлением с клавиатуры. Логика вычислений отделена от интерфейса и покрыта тестами.

## Возможности

- Сложение, вычитание, умножение, деление, проценты, 1/x, x², √ и смена знака.
- Вычисление в порядке нажатия, как в обычном калькуляторе: `2 + 3 * 4 =` даёт 20.
- При делении на ноль, корне из отрицательного числа и переполнении на экране появляется `Error`, программа продолжает работать.
- Шрифт дисплея подбирается так, чтобы число помещалось целиком при любом размере окна.
- Всё доступно с клавиатуры, включая выбор кнопок клавишей Tab.

## Запуск

Нужен Python 3.8 или новее. В установщике Python для Windows tkinter уже есть, сторонние библиотеки не нужны.

```bash
python calc_app.py
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `0`–`9`, `.` или `,` | ввод числа |
| `+` `-` `*` `/` | операции |
| `Enter` или `=` | равно |
| `%` | процент от первого числа |
| `Backspace` | стереть последнюю цифру |
| `Delete` | CE — очистить текущее число |
| `Esc` | C — полный сброс |
| `Tab` / `Shift+Tab` | выбрать кнопку |
| `Пробел` | нажать выбранную кнопку |
| `F1` | справка |

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `calculator.py` | класс `Calculator`: получает нажатия клавиш и хранит текст дисплея, ничего не знает об окне |
| `calc_app.py` | класс `CalculatorApp`: окно, кнопки, клавиатура и подбор размера шрифта |
| `test_calculator.py` | тесты логики на pytest |

Интерфейс только передаёт нажатия в `Calculator.press()` и показывает результат. Поэтому вычисления проверяются тестами без запуска окна.

## Что изменилось по сравнению с v0.3

Версия 0.3 занимала 34 строки, но была написана слишком плотно для чтения. В v0.4 код переписан с понятными именами, логика вынесена в отдельный модуль. Исправлены ошибки, на каждую есть тест:

- Если x², √ или % давали ноль при незавершённой операции, вместо нуля появлялось другое число: `5 + 0 x²` показывало 5, а затем `=` давало 10.
- Две операции подряд складывали число с самим собой: `5 + + 3 =` давало 13 вместо 8. Теперь вторая операция заменяет первую.
- Нажатие Shift, Ctrl, Alt или стрелок посреди ввода завершало вычисление и сбрасывало набранное число.
- Ввод, начатый с точки, показывал `.5` вместо `0.5`.

Добавлено: Shift+Tab, клавиши Delete, `=` и `%`, подсветка выбранной кнопки цветом.
